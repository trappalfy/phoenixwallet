Privacy Policy

Last updated: July 26, 2026

This policy covers both the Perigee Wallet website (perigeewallet.space) and the Perigee Wallet browser extension. In short: neither one collects, stores or transmits any personal or financial data.

The browser extension

  • The extension makes no network requests. There is no server behind it, no analytics, no crash reporting and no third-party SDK of any kind.
  • Nothing you enter into it — including the sample recovery phrase, a password, or transaction details — is transmitted anywhere. It exists only in the extension's local, in-memory state and is discarded when the popup closes.
  • The extension requests no browser permissions and cannot read your browsing activity, other open tabs, or any website's content.
  • This build does not create a real wallet, so there are no real private keys, balances or transactions to protect or collect in the first place. All figures shown are sample data generated locally.

This website

  • The waitlist / early-access form on this site does not submit anywhere — it is a front-end preview and no email address is stored or sent to any server.
  • The site sets no tracking cookies and runs no analytics or advertising scripts.

Future changes

If a future version of Perigee Wallet adds functionality that involves handling real user data or making network requests, this policy will be updated before that version ships, and the change will be described plainly rather than folded into a version bump.
